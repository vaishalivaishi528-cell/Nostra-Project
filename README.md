# Nostra-Project

### Project Overview
**Nostra** is a fully responsive, multi-page fashion and lifestyle e-commerce web application. It features a modern user interface inspired by real-world clothing brands, complete with dynamic product filtering, a multi-view layout, interactive image sliders, a wishlist feature, and smooth horizontal scrolling sections.

### Key Features
* **Multi-View Navigation:** Seamlessly switch between the **Home**, **Collections**, and **Contact Us** views dynamically via JavaScript without full page reloads.
* **Advanced Product Filtering:** Filter products on the fly by arrival status (`new`/`old`), occasion (`summer`, `party`, `beach`), and color, alongside real-time search functionality.
* **Interactive Horizontal Carousels:** **New Arrivals** and **Most Wanted** sections support smooth side-to-side scrolling, mouse-wheel translation, and click-and-drag panning.
* **Hero Carousel & Side Navigation:** Features an interactive hero image slider with manual controls and a slide-out mobile navigation drawer.
* **Wishlist & Form Feedback:** Interactive heart toggles for saving items to a wishlist, plus instant validation feedback for newsletter subscriptions and contact form submissions.

### Technologies Used
* **HTML5:** Semantic markup structure (`<nav>`, `<main>`, `<section>`, `<footer>`).
* **CSS3:** Flexbox and CSS Grid for layout structuring, custom scrollbar styling, sticky headers, and responsive media queries for mobile/tablet breakpoints.
* **JavaScript (ES6+):** DOM manipulation, dynamic rendering of product grids from a local JSON dataset, event listeners, and interactive UI state control.
* **External Libraries:** Google Fonts (`Poppins`), Font Awesome (v6.5.1), and Unsplash.
